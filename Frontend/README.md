# 🎨 Medium Frontend - React 19 + TypeScript + Vite

This directory contains the client-side single page web application for the **Medium Blogging Platform**.

## 🚀 Key Features

- **React 19 & TypeScript**: Full type safety and high performance client rendering.
- **Tailwind CSS v4**: Modern utility-first styling with editorial layouts (*Fyrre* & *Gazette*).
- **Lucide Icons**: Crisp, responsive UI icons.
- **Zod Shared Validation**: Direct integration with `@aarjav-shukla/medium-common` for runtime client validation.
- **Modular Components**: Modals for article creation, reader view, responsive navbar, and user profile management.

## 🛠️ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```

For full setup details, environment configuration, backend integration, and API documentation, please refer to the [Root README](../README.md).
